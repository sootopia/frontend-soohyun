# Soohyun Park — Frontend Portfolio

프론트엔드 개발자 박수현의 포트폴리오 사이트입니다.

## 적용 기술 스택

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Framer Motion
- next-themes

## 프로젝트 구동

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000)에서 확인할 수 있습니다.

```bash
npm run build
npm run start
```

## 프로젝트 구조

```
src/
  app/            # 레이아웃, 글로벌 스타일, 메인 페이지
  components/
    layout/       # Header, Footer, Navbar, ThemeToggle
    sections/     # Hero, Strengths, Projects, Experience, Contact
    ui/           # Button, Container, SectionTitle 등
  lib/            # 사이트 데이터, 유틸
```
